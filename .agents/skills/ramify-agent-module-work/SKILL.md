# Implement assisted plan work

Receive the plan outcome, relevant acceptance references, project instructions and any module focus from the coordinator. Inspect the existing code, generated views and applicable `.principles.md` or `.spec.md` commitments before changing behavior. A filename alone does not establish whether a proposed principle is adopted; preserve its source and status.

Treat module focus as a way to concentrate context. Edit any provider, consumer, test or configuration file needed for a coherent change. Coordinate overlapping writers with the coordinator. No module scope expansion request is needed. Honor the project's own protected commitments and Git rules; do not weaken a requirement to make checks pass.

Implement and verify the intended behavior. Report changed behavior, relevant checks, remaining risks or integration work, and any protected commitment that would need an explicit decision. Leave candidate commit preparation to the native workflow under the target project's authorization. Ramify-agent's Pi assessment will independently review the resulting committed candidate; your report does not substitute for that assessment.
