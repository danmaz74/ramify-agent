# Reviews

Prepares mechanical review evidence against a fixed candidate and validates candidate references and reviewer submissions. This module owns snapshot path restrictions and tools, bounded patch delivery, captured design guidance and review briefings. It receives Git facts through the evidence contract and makes no semantic judgment about the candidate.

Workflow owners retain reviewer session lifetime, scheduling policy, durable records and CheckFinding coordination. This provider supplies the shared reader queue, concern binding and candidate ownership signals, reconciliation submission schema/validation and factual message rendering. Autonomous adapters retain work-item authority and records; assistance supplies job authority. Both use the same implementations. `prepareReview` returns the briefing, candidate patch section, snapshot conveniences, ordinary candidate shell and a submission validator. Reviewers select relevant inspection and report conclusions and meaningful limitations. Legacy inspected/missing inventories remain readable but do not govern acceptance or turn unread supplemental files into required gaps. Concern grounds bind to candidate bytes regardless of the inspection tool chosen. The inline patch budget remains 200 KiB.

Automated design preparation uses affected-owner README context and document starting points supplied by the assigning architect. It does not scan for every principles filename. The reviewer may inspect other relevant originals on demand; a filename alone establishes neither applicability nor adoption. Assisted iteration preparation supplies the goal, acceptance text, selected guidance and earlier decisions. The original captured plan remains available through retained evidence; final assessment receives the complete plan.

The ordinary `shell` runs each command in a disposable detached checkout of the intended candidate, with the project cwd preserved for projects nested in a repository. It supports compressed and large evidence. Reviewers are instructed not to edit source; shell access is not a write sandbox. A fresh call starts again from the candidate, and owned checkouts are cleaned after command settlement.
