# Planning

Performs captured plan intake, principles extraction, initial architecture,
document checks and validation. It derives the entry assignments, hypothesis and
registry revisions, initial work items and scenarios together. Immutable catalog
and incorporation evidence is staged before the lifecycle owner commits the
single accepted event and its entire record bundle.

`performInitialAnalysis` receives captured inputs, immutable view/baseline facts
and a narrow read-only task executor. Its explicit ports stage evidence, capture
an authorized contingent repair assignment and propose the accepted transition.
It receives no run object, log, mutex or live invocation maps. The lifecycle owner
retains admission, current-authority fencing, approval/stop waiting and commits.

`planningRecords` selects this owner's committed records from immutable replay
lines. Accepted evidence reads take the captured manifest and accepted immutable
references, preserving hash, path, UTF-8, schema and unavailable diagnostics.
