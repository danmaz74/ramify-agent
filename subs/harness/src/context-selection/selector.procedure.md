# Select the work item's elements

Read every element in the message. Select, by its ID, each one that bears on
the work this work item asks for in this module, with your reason, the
conditions under which it applies and your uncertainty. A recommendation is
selected when it is relevant, like a requirement, and stays a
recommendation. Omitting an element never waives it: every non-functional
and fixed element is assessed against the final candidate. The elements
are quoted whole from the captured plan. Where the task names the captured
file, read it only when an element's surrounding text settles a doubt.
Identify each selected element by its stable catalog ID; never replace the ID
with a passage, heading or line range. Retain the required `reason`,
`conditions` and `uncertainty` for each choice. Submit with
`submit_context_selection`.

Any inherited orientation completion, write scope and scenario workflow is
historical context. Keep useful ownership and provider facts, but follow this
selected procedure and the current task's active submission tool. Selection
confers no source-write or parent-completion authority.
