# Plan 42 semantic identity inventory

Every semantic ID has a namespace and a descriptive name. Author proposals use `draft:<namespace>:<name>`; acceptance records `<namespace>:<name>`. Generated semantic names derive from accepted relationships and keep a collision-safe discriminator where a source can repeat. The existing author task handles occupied names, invalid references and correction before atomic publication. Retirement records replacement lineage and rebinds affected active references under the existing correction authority. Technical invocation, session, operation, event, gate, audit receipt, attempt and iteration counters are separate from semantic identities. External test names, paths, exports and project/plan names retain their own contracts.

Current readers and public selectors use the complete accepted ID. A recorded semantic format the harness cannot read yields an inspectable query or command error without mutating the record. Source and prompt hash changes alone do not veto accepted work. Current restart, retry and fork paths preserve accepted IDs, reference bindings, author task source and atomic publication.
